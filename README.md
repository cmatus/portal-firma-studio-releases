# PortalFirma Studio: descargas

Aquí se publican los instaladores de **PortalFirma Studio**. Descarga la última versión en **[Releases](https://github.com/cmatus/portal-firma-studio-releases/releases/latest)**.

| Sistema | Archivo |
|---|---|
| Windows 10/11 (64 bits) | `PortalFirma-Studio-Setup-X.exe` |
| Mac con chip Apple (M1, M2, M3…) | `PortalFirma-Studio-X-arm64.dmg` |
| Mac con Intel | `PortalFirma-Studio-X-x64.dmg` |

- **Windows:** si aparece «Windows protegió su PC», presiona *Más información → Ejecutar de todas formas*. Después la app se actualiza sola.
- **Mac:** la primera vez, clic derecho sobre la app → *Abrir*. Cuando haya una versión nueva, la app avisa y abre esta página.

> Versión en desarrollo y pruebas.

Este repositorio solo contiene los instaladores; el código es privado.
